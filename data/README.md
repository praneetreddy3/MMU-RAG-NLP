# Data Directory

## Overview

This directory contains all data files for the MMU-RAG-NLP project.

## Input Data

### t2t_test_participants.jsonl
- **Purpose:** Input dataset for the system
- **Format:** JSON Lines (one JSON object per line)
- **Total Queries:** 299
- **Queries for Corpus Creation:** 117
- **Fields:** 
  - `id` (str): Query identifier (e.g., "V_0862")
  - `query` (str): Natural language question

**Sample Format:**
```json
{"id": "V_0862", "query": "Who was the first President of the United States?"}
{"id": "V_0863", "query": "What is the capital of France?"}
```

### corpusbaseline.jsonl
- **Purpose:** Pre-constructed Wikipedia corpus for baseline RAG
- **Format:** JSON Lines (one passage per line)
- **Total Passages:** 150,000+
- **Chunk Size:** ~256 tokens with overlap
- **Fields:**
  - `id` (str): Passage identifier
  - `text` (str): Passage content
  - `title` (str): Source Wikipedia article title
  - `section` (str): Section within article

**Used By:** `BaselineCode.ipynb` (static corpus RAG)

## Output Data

### mmu_rag_results.jsonl
- **Purpose:** Detailed results from improved MMU-RAG system
- **Generated By:** `FinalcodeAIT626project.ipynb`
- **Format:** JSON Lines (one result per query)
- **Fields:**
  - `id` (str): Query identifier
  - `query` (str): Original question
  - `cluster_id` (int): Assigned cluster (0-7)
  - `answer` (str): Generated answer
  - `confidence` (float): Confidence score (0.0-1.0)
  - `sources` (list): Retrieved passage titles
  - `alt_answers` (list): Alternative answers (2 samples)
  - `num_sources` (int): Number of retrieved passages

**Sample Result:**
```json
{
  "id": "V_0862",
  "query": "Who was the first President of the United States?",
  "cluster_id": 2,
  "answer": "George Washington was the first President of the United States, serving from 1789 to 1797.",
  "confidence": 0.89,
  "sources": ["George Washington", "President of the United States"],
  "alt_answers": ["Washington became the first U.S. President...", "The first president of..."],
  "num_sources": 2
}
```

### mmu_rag_summary.csv
- **Purpose:** Summary statistics for analysis and evaluation
- **Generated By:** `FinalcodeAIT626project.ipynb`
- **Format:** CSV (comma-separated values)
- **Columns:**
  - `id`: Query identifier
  - `query`: Original question
  - `cluster_id`: Assigned cluster
  - `answer`: Generated answer
  - `confidence`: Confidence score
  - `num_sources`: Number of sources

**Used For:** Quick analysis, Excel/Pandas exploration, statistical summaries

### rag_results_baseline.jsonl
- **Purpose:** Baseline system predictions (for comparison)
- **Generated By:** `BaselineCode.ipynb`
- **Format:** JSON Lines
- **Fields:**
  - `id`: Query identifier
  - `query`: Original question
  - `answer`: Baseline-generated answer
  - `retrieved_passages`: List of retrieved passage texts
  - `retrieval_scores`: Cosine similarity scores

**Used For:** Comparing baseline vs. improved system performance

## Data Quality Notes

1. **Query Preprocessing:**
   - Lowercasing applied
   - Whitespace normalized
   - Special characters preserved for semantic meaning

2. **Corpus Chunks:**
   - Overlap of 50 tokens between consecutive passages
   - Sections with <100 tokens removed
   - Duplicate passages deduplicated

3. **Dynamic Corpus Construction:**
   - For improved system, corpus is built dynamically per cluster
   - Queries similar to cluster keywords retrieve relevant Wikipedia articles
   - Corpus size varies by cluster (typically 10K-30K passages)

4. **Answer Generation:**
   - Generated via FLAN-T5 with greedy decoding (deterministic)
   - Alternative answers sampled with temperature=0.8
   - Answers post-processed to remove excessive punctuation

## Reproducibility

To reproduce results:

1. **Ensure input data present:** `t2t_test_participants.jsonl`
2. **Run improved system:**
   ```bash
   jupyter notebook notebooks/FinalcodeAIT626project.ipynb
   # Cell → Run All
   ```
3. **Output generated:** `mmu_rag_results.jsonl`, `mmu_rag_summary.csv`
4. **Verify results:** Check `results/` folder

**Reproducibility Notes:**
- Random seed set to 42 in all cells
- K-Means clustering is deterministic with fixed seed
- FLAN-T5 greedy decoding is deterministic
- Wikipedia API calls may have slight variability (pages updated)
